# AGENTS.md

## Project
Kiwi HTTP Evolution — ResourceHandler + QuerySpec + Lightweight RSQL backend with Jetty 12, Java 25, and PostgreSQL.

## Stack
- Language: Java 25
- Framework: Jetty 12 (embedded), Hexagonal Architecture
- Build: Maven (multi-module), Makefile orchestration
- Database: PostgreSQL 16
- Testing: JUnit 5, Testcontainers 1.19.7
- Containerization: Docker, Helm charts

## Commands
```bash
# Build
./mvnw clean compile -DskipTests

# Test
./mvnw test

# Quality checks
./mvnw verify -Pquality

# Run locally (development)
./mvnw -pl backend/java/kiwi-parent/kiwi-bootstrap spring-boot:run

# Run with Docker
make backend-run-image

# Database migrations
make db-migrate
```

## Architecture
Hexagonal (Ports & Adapters). Core domain in `kiwi-core`, repository interfaces in `kiwi-ports`, PostgreSQL implementations in `kiwi-infra-postgres`, HTTP transport in `kiwi-transport-jetty`. Supports RSQL filtering, QuerySpec abstraction, and safe SQL generation.

## Guardrails
- Never modify existing Flyway migrations (db/sql/V*.sql)
- Always use PreparedStatements for SQL queries
- Field whitelisting required for RSQL selectors
- Sort fields must be validated through SortMapper
- Limit must be clamped (1–200)
- Never commit `.env` files or secrets
